Manuscript title: Landscape configuration influences abruptness of state shifts in shallow coral reefs

Submission: Ecology

Study abstract: Numerous ecosystems can undergo rapid and difficult to reverse changes to different, often undesirable, states. Spatial processes and habitat heterogeneity can modify the abruptness and reversibility of these catastrophic ecosystem shifts. Experimental evidence in coral reefs shows that individual patch reefs can represent alternate stable states of coral and macroalgal dominance, but it is unclear how this bistability within habitat patches scales up to produce state transitions across entire landscapes. Here we used a spatial model of coral-macroalgae competition to explore how spatial heterogeneity of reef habitat influences the bistability of the system and the abruptness of state shifts at a landscape scale. The model operates on a two-dimensional grid, where each cell represents either physical reef habitat, where coral and macroalgae can grow, or sand, which is inhospitable to these taxa. We explored many different habitat configurations, varying the amount and the aggregation of reef habitat, and found that when habitat was more abundant and aggregated, the macroalgae-dominated state was favored and shifts between alternate states were abrupt. When habitat was more fragmented, the coral state was favored and shifts between states were gradual, allowing localized regions of coral and macroalgal dominance to coexist. We then confronted these model predictions with spatially-explicit field data and found the qualitative patterns we predicted. Our study demonstrates that the landscape configuration of reef habitat can influence the abruptness of coral-macroalgae state shifts and provides insight on what locations of a reef landscape may be most susceptible to an abrupt state shift. More generally, these results highlight the importance of considering spatial processes and habitat heterogeneity when studying state shifts in ecosystems consisting of multiple stable states.

Repository README: This repository contains all the necessary scripts to replicate results in the associated text. To replicate results, the reader first needs to download the data from the following DOI: 

doi:10.6073/pasta/9886be23c11ecfc03a422dcbf05a351f

and place this into the data folder. The user then can navigate to the "scripts" folder and run the contained scripts after setting the working directory to the repository parent location on your machine. Note that this requires installing Julia on the computer. 

Running the model: The "run_model_julia_cluster.R" and "run_model_julia_nocluster.R" scripts will run the model with the cluster algorithm and spatially random algorithm, respectively. Together, they will complete the 480 replicate landscapes, with all the listed herbivory values and intial conditions. They are set up with default parameters, so replicating some results  will require changing some paramters at the top of the script (e.g., doubling the scale parameter of dispersal will require changing the "disp_a" parameter to 1.5). These use the "model_functions.R" and "spatial_briggs_for_R.jl" scripts to complete the model, and they are set up for the default parameter values. For the sensitivity analyses of spatial parameters, the "run_model_sensitivity.R" script can be run. For the sensitivity analyses of nonspatial parameters, the "run_nonspatial_sensitivity.R" script can be run. With these, you can replicate the analyses. To replicate the sstability analysis, there is the run_numerical_stability.R script. This runs the model for each herbivory value described in the text with 99 initial conditions on each of the eight landscapes used in sensitivity analyses. The outputs are .RDS and contains the entire time series of each cell in each model run. These are large files, so these raw outputs are not included in the data package (but can be generated using this script). The plots in Figure S3 only use outputs from two of the eight landscapes (0_0.1_4 and 0_0.8_5), and the raw outputs from run_numerical_stability.R are put through FigureS3_output_condensing.R to generate the stability_figure_plotting.csv used for plotting Figure S3. Again, the raw data (from run_numerical_stability.R) are not included but can be generated using run_numerical_stability.R and then condensed by FigureS3_output_condensing.R recreate the exact results. By default, the write.csv() (and saveRDS) lines are commented out to prevent overwriting data, but they can be uncommented if desired.

Statistical analyses: The statistical tests shown in Figure 4 can be found in the Figure4.R script. They statistical models are created alongside the figure and the p-values described in the manuscript text are from these tests.

Replicating plots: The scripts for generating the data figures are labeled by the figure in the text they can replicate. All the necessary data are provided, so these should run without issue or needing to re-run the entire modeling procedure. This includes supplementary figures. There is also a script to generate the example random landscapes shown in the manuscript (Example_landscape_generator.R), and there is a separate script to recreate the example landscapes for Figure 3 (Figure3_example_landscapes.R).

Functions and others: The "model_functions.R" and "spatial_briggs_for_R.jl" files contain functions and other code necessary to run the models and conduct some analyses on the model outputs for plotting. Each custom R function is described in the script, and the Julia (jl) file just sets some initial values and loads in the parameters as an array prior to the solver being run.
